**Azure Data Migration Solutions**

| **Feature / Service** |                                 **Azure Migrate**                                  |                             **Azure Data Box**                             |
| --------------------- | :--------------------------------------------------------------------------------: | :------------------------------------------------------------------------: |
| **Transfer Type**     |                                 Real-time / Online                                 |                  Asynchronous / Offline (Physical device)                  |
| **Primary Focus**     |        Whole-workload migration (VMs, databases, web apps, infrastructure)         |                Bulk data transfer (terabytes to petabytes)                 |
| **Best Scenario**     |      Moving active servers, databases, and running apps directly to the cloud      |         Network bandwidth is limited or online upload is too slow          |
| **Mechanism**         | Central cloud portal with native discovery, assessment, and live replication tools | Proprietary, ruggedized physical storage device shipped to your datacenter |
| **Data Security**     |                      Encrypted in-transit network connections                      | AES 256-bit encrypted disks; wiped post-upload via NIST 800-88r1 standards |

**Key Highlights of Each Service**

**1. Azure Migrate (Online Migration Hub)**

- **Unified Dashboard:** Provides a centralized management portal to plan, assess, and execute migration projects end-to-end.
    
- **Discovery & Assessment:** Scans on-premises VMware, Hyper-V, physical servers, and databases to estimate Azure sizing, costs, and readiness.
    
- **Extensible Ecosystem:** Integrates native tools (_Server Migration_, _Database Migration_, _Web App Migration_) alongside third-party ISV solutions.
    
**2. Azure Data Box (Offline Mass Storage)**

- **Physical Shipping Workflow:** Order device from the Azure Portal $\rightarrow$ Connect & load data locally over high-speed networks $\rightarrow$ Ship device back via regional carrier $\rightarrow$ Automatic ingestion into Azure Blob/Files.
    
- **Capacity Variations:** Options range from _Data Box Disk_ (up to 35 TB across SSDs), standard _Data Box_ (~80 TB usable capacity), up to _Data Box Heavy_ (770 TB usable capacity) or Next-Gen variants.
    
- **Common Use Cases:**
    - **One-time migration:** Moving massive legacy media libraries, tape archives, or VM backup farms.
    - **Initial Bulk Seed:** Offline bulk load of baseline historical data, followed by online incremental syncs.
    - **Data Export:** Secure offline retrieval of cloud data for disaster recovery or regulatory compliance.
