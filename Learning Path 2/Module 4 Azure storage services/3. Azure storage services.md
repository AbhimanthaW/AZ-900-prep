Azure Storage offers key services, architectural benefits, and Blob access tiers designed to balance cost against latency:

**Core Data Services**

- **Azure Blobs:** Unstructured object storage for media, logs, backups, and big data analytics (via Data Lake Storage Gen2).
- **Azure Files:** Fully managed SMB/NFS file shares mounted by cloud or on-premises machines.
- **Azure Queues:** Reliable asynchronous message store (up to 64 KB per message) for decoupled workflows.
- **Azure Disks:** Virtualized block-level storage volumes for Azure VMs.
- **Azure Tables:** NoSQL key-attribute store for rapid, non-relational structured data.

**Blob Storage Access Tiers**

| **Access Tier** | **Intended Usage Pattern**            | **Minimum Retention** | **Latency**                  | **Cost Trade-off**                               |
| --------------- | ------------------------------------- | --------------------- | ---------------------------- | ------------------------------------------------ |
| **Hot**         | Active, frequently accessed data      | None                  | Milliseconds                 | Highest storage cost, lowest access/read cost    |
| **Cool**        | Infrequently accessed data            | 30 days               | Milliseconds                 | Lower storage cost, higher access cost           |
| **Cold**        | Rarely accessed data                  | 90 days               | Milliseconds                 | Lower storage cost than Cool, higher access cost |
| **Archive**     | Long-term backup & historical records | 180 days              | Hours (requires rehydration) | Lowest storage cost, highest access cost         |

_Note: Deleting or moving blobs prior to their minimum retention period triggers early deletion charges._

**Core Benefits**

- **Durable & Available:** Replicated across hardware, availability zones, or paired regions.
- **Secure:** Automatic encryption at rest and in transit, with granular Azure RBAC and SAS key access control.
- **Managed & Scalable:** Azure maintains underlying infrastructure while scaling capacity seamlessly.
- **Globally Accessible:** Interoperable via REST APIs, SDKs (.NET, Python, Java, etc.), CLI, PowerShell, and Azure Storage Explorer.
