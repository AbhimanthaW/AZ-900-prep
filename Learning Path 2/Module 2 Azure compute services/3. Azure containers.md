**containers**
- virtualisation environment

run multiple containers on a single physical / virtual host

don't manage OS for container

lightweight + designed to be created, scaled out, and stopped dynamically

can create and deploy virtual machines as application demand increases

help respond to changes on demand and restart quickly after a crash or hardware interruption

popular container engines = *Docker*

- **Azure Container Instances (ACI)**
    - **Type:** PaaS (Platform as a Service)
    - **Key Feature:** Fastest and simplest way to run containers without managing virtual machines.
    - **Mechanism:** Upload containers and the service runs them.
        
- **Azure Container Apps**
    - **Type:** PaaS
    - **Key Feature:** Removes container management overhead and includes **built-in load balancing and auto-scaling**.
        
- **Azure Kubernetes Service (AKS)**
    - **Type:** Container Orchestration Service
    - **Key Feature:** Manages the full lifecycle and orchestration of container fleets efficiently.

**Using Containers in Solutions**
- **Microservices Architecture:**
    - Splits solutions into smaller, independent components (e.g., front end, back end, storage).
    - **Key Advantages:**
        - **Independent Maintenance & Updates:** Update or modify components without impacting others.
        - **Targeted Scaling:** Scale specific high-traffic services (such as the back end) without scaling the whole application.
