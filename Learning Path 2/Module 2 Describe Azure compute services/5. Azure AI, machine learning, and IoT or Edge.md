1. **Azure AI Services**
	- **Azure AI Services:** Prebuilt capabilities (vision, language, speech, document processing) integrated via APIs without training models from scratch.
	- **Azure OpenAI Service:** Enterprise generative AI (chat, content creation) with security and governance.
	- **Agentic AI Patterns:** An architecture combining AI models with context, instructions, and tools to complete multi-step goals (an application pattern, not a standalone compute service).
	
2. **Azure Machine Learning**
	- **Azure Machine Learning:** Complete end-to-end platform for building, training, experimenting, and managing **custom ML models**.

3. **IoT & Edge Services**
	- **Azure IoT Hub:** Central messaging hub for secure, bi-directional communication with IoT devices. 
	- **Azure IoT Central:** A SaaS platform simplifying device management and solution creation.
	- **Azure IoT Edge:** Extends cloud analytics and workloads to run directly on physical edge devices.
	- **Data Flow:** Telemetry sent via IoT Hub $\rightarrow$ Cloud analytics process data $\rightarrow$ Updated models deployed locally via IoT Edge.
