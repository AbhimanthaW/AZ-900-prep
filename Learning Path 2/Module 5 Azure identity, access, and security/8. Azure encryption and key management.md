**Core Concept**

- **Encryption:** Protects data confidentiality by converting information into an unreadable format for unauthorized users.

**Encryption Types**

- **Encryption at Rest:** Protects stored data (e.g., databases, disks, storage accounts).
- **Encryption in Transit:** Protects moving data (e.g., between APIs, cloud services, and user devices).
    
**Azure Key Vault**

- **Function:** Centralized service for securely storing and controlling access to **secrets** (passwords/connection strings), **encryption keys**, and **certificates**

- **Key Benefits:**
    
    - **Removes Hard-Coded Credentials:** Applications fetch secrets dynamically at runtime using managed identities.
        
    - **Role Separation:** Controls access by separating who can view, use, or rotate credentials.
        
    - **Lifecycle Management:** Supports automated key rotation, expiration alerts, and access usage auditing.
