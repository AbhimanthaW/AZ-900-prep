**Core Concept**
- **Authentication:** Verifies identity (person/service/device) via credentials.
    
**Single Sign-On (SSO)**
- **Function:** Log in once to access multiple trusted applications.
- **Benefits:** Reduces password fatigue, reset requests, and simplifies access lifecycle management.
- **Risk:** Security depends entirely on the initial login method.

**Multifactor Authentication (MFA)**
- **Function:** Requires 2+ verification factors to grant access.
- **Categories:**
    - **Something you know:** Password, PIN, challenge question.
    - **Something you have:** Mobile device code, app prompt.
    - **Something you are:** Biometrics (fingerprint, face scan).
        
- **Microsoft Entra MFA:** Native Microsoft service providing app notifications or phone calls as second factors.
    
**Passwordless Authentication**
- **Concept:** High security + high convenience. Replaces passwords with a trusted device combined with biometrics or a PIN.

|**Option**|**Key Features**|
|---|---|
|**Windows Hello for Business**|Tied to a designated PC; relies on PIN/biometrics + PKI for SSO.|
|**Microsoft Authenticator App**|Converts iOS/Android into credentials via push notifications + number matching.|
|**FIDO2 Security Keys**|Unphishable hardware (USB/NFC/Bluetooth) based on WebAuthn open standard.|
