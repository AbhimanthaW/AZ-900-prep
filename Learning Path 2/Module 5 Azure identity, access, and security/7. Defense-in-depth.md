**Core Concept**

- **Defense-in-Depth:** A layered security strategy that uses multiple defensive mechanisms to protect data, eliminating reliance on any single layer and slowing down attacks.
    
**7 Security Layers**

|**Layer**|**Primary Role**|**Key Protection Measures**|
|---|---|---|
|**Physical Security**|First line of defense; protects datacenter hardware and facilities.|Physical access controls, building safeguards.|
|**Identity & Access**|Controls access to infrastructure, sign-ins, and change control.|SSO, MFA, event and change auditing.|
|**Perimeter**|Defends against network-based attacks across resources.|DDoS protection, perimeter firewalls, threat alerting.|
|**Network**|Limits connectivity between internal resources.|Network segmentation, default-deny policies, internet access restrictions.|
|**Compute**|Secures access to virtual machines and endpoint devices.|Endpoint protection, OS patching, secure VM access.|
|**Application**|Ensures software is secure and free of vulnerabilities.|Secure development lifecycles, secret management (e.g., Azure Key Vault).|
|**Data**|Secures operational, customer, and stored data (the primary target).|Data access controls, encryption at rest, encryption in transit.|
