**Core Concept**

- **Zero Trust:** A security model operating on the premise of "never trust, always verify." It assumes breach by default and treats all access requests as originating from an untrusted network.
    
**3 Guiding Principles**

- **Verify Explicitly:** Always authenticate and authorize using all available data points (identity, location, device health, risk state).
    
- **Use Least Privilege Access:** Grant minimal required permissions using adaptive, risk-based policies alongside Just-In-Time (JIT) and Just-Enough-Access (JEA).
    
- **Assume Breach:** Limit attack radius through micro-segmentation, end-to-end encryption, continuous analytics, and real-time threat detection.

**Traditional vs. Zero Trust Model**

|**Feature**|**Traditional Perimeter Model**|**Zero Trust Model**|
|---|---|---|
|**Trust Assumption**|Inside network = Trusted|No network location is trusted|
|**Access Control**|Boundary-based (VPNs, firewalls)|Context-aware & dynamic per request|
|**Decision Factors**|Network location / IP address|Identity, device state, app risk, real-time telemetry|
