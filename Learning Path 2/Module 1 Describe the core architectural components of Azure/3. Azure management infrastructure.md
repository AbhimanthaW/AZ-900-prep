**Resource groups**
- Every resource must belong to exactly one resource group. 
- You can move some resources between groups, but a resource is only associated with one group at a time. 
- Resource groups can't be nested, and they can't be renamed after creation, so choose a clear naming convention from the start.
- Actions you apply to a resource group affect all resources inside it.

**Azure subscriptions**
- Azure subscription links to an Azure account (identity in Entra ID or in a directory that Microsoft Entra ID trusts)

**Azure management groups**
- **Hierarchy Structure:** Management groups sit above Azure subscriptions, - a hierarchy that can nest up to 6 levels deep (excluding the Tenant Root Group and subscription levels)

- **Inheritance & Governance:** Policies, access controls (RBAC), and compliance rules applied to a management group are automatically inherited by all subscriptions and resources beneath it.

- **Tenant Root Group:** Every Microsoft Entra tenant has one top-level Tenant Root Group where all other management groups and subscriptions ultimately converge, allowing for global policy enforcement.

- **Primary Use Case:** Best suited for scaling organizations with multiple subscriptions across teams or geographies that require centralized governance and access management.

**Azure Management Groups & Hierarchy Key Takeaways**

- **Unified Policy Control:** Policies applied to a management group (such as restricting VM regions to "US West") inherit down to all child subscriptions and resources, and cannot be overridden by resource or subscription owners.
    
- **Streamlined Access Management (RBAC):** Creating a single Role-Based Access Control (RBAC) assignment at the management group level automatically grants access across all descendant management groups, subscriptions, and resources.
    
- **Directory Capacity:** A single Microsoft Entra directory supports up to 10,000 management groups.
    
- **Strict Single Parent Rule:** Each management group and subscription can have only one direct parent, enforcing a clear tree structure.
