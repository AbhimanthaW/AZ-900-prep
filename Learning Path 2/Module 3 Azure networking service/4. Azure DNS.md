**Overview**

- **DNS Hosting Service:** Provides reliable name resolution using Microsoft Azure infrastructure, sharing the same credentials, APIs, tools, and billing as your other Azure services.
    
**Key Benefits & Features**

- **Reliability & Performance:** Hosted on a global network of DNS name servers using **anycast networking** to ensure the closest available server handles each query with high availability.
    
- **Security:** Built on Azure Resource Manager, providing features like **Azure RBAC**, activity logs, and resource locks.
    
- **Ease of Use:** Manage records via the Azure portal, PowerShell, Azure CLI, REST APIs, or SDKs. Supports both internal Azure and external resources.
    
- **Private Domains:** Allows custom domain names inside private virtual networks instead of default Azure-provided names.
    
- **Alias Records:** Points record sets directly to Azure resources (such as public IPs, Traffic Manager profiles, or CDN endpoints) so they automatically update if underlying IP addresses change.
    
 **Important Limitation**

- **No Domain Purchasing:** You cannot buy domain names directly through Azure DNS. Domains must be purchased via App Service domains or a third-party registrar, and then hosted in Azure DNS for record management.
