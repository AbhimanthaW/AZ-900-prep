
- **Purpose:** Data governance, risk, and compliance solutions
- Provides a **unified view of data** across:
    - On-premises
    - Multicloud
    - SaaS
        
### Key Capabilities
- Automated data discovery
- Sensitive data classification
- End-to-end data lineage
    
### Two Main Solution Areas

#### 1. Risk and Compliance
- Works with Microsoft 365 services such as:
    - Teams
    - OneDrive
    - Exchange
        
- Helps:
    - Protect sensitive data across clouds, apps, and devices
    - Identify data risks
    - Manage regulatory compliance
    - Support compliance requirements

#### 2. Unified Data Governance
- Manages data across:
    - Azure
    - SQL databases
    - Hive databases
    - On-premises systems
    - Other clouds (e.g. Amazon S3)
        
- Helps:
    - Map the entire data estate
    - Classify data and track data lineage
    - Identify sensitive data locations
    - Help users securely discover valuable data
    - Analyze how data is stored and used
    - Manage data access securely and at scale
