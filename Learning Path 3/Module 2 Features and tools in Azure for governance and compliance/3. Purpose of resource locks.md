
- **Purpose:** Prevent accidental deletion or modification of Azure resources
- Works **regardless of Azure RBAC permissions**
- Can apply to:
    - Individual resources
    - Resource groups
    - Subscriptions
        
- **Inherited:** Lock on a resource group → applies to all resources within it
    
### Types of Locks

|Lock|Effect|
|---|---|
|**Delete**|Read + modify allowed; **delete blocked**|
|**ReadOnly**|Read allowed; **modify + delete blocked**|

- **ReadOnly** ≈ Reader-level access
    

### Managing Locks

- Azure Portal
- PowerShell
- Azure CLI
- ARM templates
    
### Modifying a Locked Resource

1. **Remove the lock**
2. Perform the permitted action
3. Reapply the lock if required

- Even **Owners** must remove the lock before performing a blocked action
