
- **Purpose:** Collect, analyze, and act on monitoring data

- Works across:
    - Azure
    - On-premises
    - Multicloud
        
- Collects **logs + metrics** from:
    - Applications
    - Operating systems
    - Networks
- Provides dashboards, queries, and alerts

### Log Analytics
- Azure portal tool for querying Azure Monitor data
- Supports simple filtering → advanced trend analysis

### Azure Monitor Alerts
- Trigger when a defined condition is met
- **Alert rule:** Defines the condition
- **Action group:** Defines notifications/actions

- Types:
    - **Metric alerts:** e.g. CPU > 80%
    - **Log alerts:** e.g. specific error pattern
        
- Action groups reusable across **Monitor, Service Health, Advisor**
    
### Application Insights
- Azure Monitor feature for **application performance + usage**
- Works with Azure, on-premises, and other clouds

- Setup:
    - SDK
    - Application Insights agent
        
- Monitors:
    - Request rates, response/failure times
    - Dependencies
    - Page loads, users, sessions
    - CPU, memory, network
        
- **Availability tests:** Synthetic requests to verify application responsiveness
