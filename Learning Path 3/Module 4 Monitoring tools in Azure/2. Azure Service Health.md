
- **Purpose:** Monitor Azure service/resource health

|View|Scope|Purpose|
|---|---|---|
|**Azure Status**|Global|Overall Azure service/region health|
|**Service Health**|Services/regions you use|Outages, planned maintenance, advisories|
|**Resource Health**|Individual resource|Status/problems of a specific resource|

- Alerts can notify you automatically
- Historical alerts help identify recurring issues
- Provides support links during incidents
