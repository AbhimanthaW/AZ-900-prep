
### Main Tools
- **Azure Portal**
- **Azure Cloud Shell**
- **Azure PowerShell**
- **Azure CLI**
- **Copilot in Azure**

### Azure Portal
- Web-based **GUI** for managing Azure
- Create, manage, and monitor resources
- Custom dashboards
- Accessibility options
- Highly resilient and continuously updated
- No maintenance downtime

### Azure Cloud Shell
- **Browser-based shell**, no local installation required
- Authenticated with Azure credentials
- Supports:
    - **Azure PowerShell**
    - **Azure CLI (Bash)**
        
### Azure PowerShell
- Uses **PowerShell cmdlets**
- Calls Azure REST API
- Useful for:
    - One-off management tasks
    - Resource setup/maintenance
    - Complex deployments
    - Automation through scripts
- Available on **Windows, Linux, Mac**
- Can run through Cloud Shell

### Azure CLI
- Command-line tool using **Bash syntax**
- Functionally similar to Azure PowerShell
- Supports:
    - Individual tasks
    - Complex operations
    - Automation/scripts
- Available on **Windows, Linux, Mac**
- Can run through Cloud Shell
- Choice between CLI and PowerShell mainly depends on preferred syntax/language

### Copilot in Azure
- **AI assistant** for Azure operations
- Natural-language guidance
- Can assist with:
    - Exploring services
    - Understanding configurations
    - Drafting commands/scripts
    - Multi-step operational tasks
- **Always validate** recommendations, permissions, and production changes
