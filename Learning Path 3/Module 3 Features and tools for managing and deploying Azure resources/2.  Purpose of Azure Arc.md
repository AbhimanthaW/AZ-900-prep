
- **Purpose:** Unified management of **Azure, on-premises, and multicloud** resources
- Extends **Azure Resource Manager** capabilities beyond Azure
- Provides consistent:
    - Governance
    - Compliance
    - Monitoring
    - Management
    
### Key Capabilities
- Project non-Azure resources into **Azure Resource Manager**
- Manage resources from different environments as if they were in Azure
- Use familiar Azure management services across environments
- Supports hybrid ITOps + DevOps practices
- **Custom locations:** Abstraction layer for Azure Arc-enabled Kubernetes clusters and extensions

### Supported Non-Azure Resources
- **Servers**
- **Kubernetes clusters**
- **Azure data services**
- **SQL Server**
- **Virtual machines** _(preview)_

### Example
- Azure + on-premises + another cloud
- Azure Arc → centralized governance, policies, monitoring, and inventory from Azure
