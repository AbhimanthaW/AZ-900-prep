
**Consumption-based pricing:** Pay only for resources used; costs scale with usage.

1. **Resource Type**

- Cost depends on:
    - Resource type
    - Resource settings/configuration
    - Region
    - Amount of resources used
- Examples:
    - **Storage:** data type, access speed, backups, region
    - **VM:** OS/software licensing, CPU/cores, storage, networking

2. **Consumption**

- **Pay-as-you-go:** Pay for actual usage
    - More usage → higher cost
    - Less usage → lower cost
- **Reservations:** 1- or 3-year commitment → lower cost
- **Savings Plan for Compute:** Commit to hourly spend for 1 or 3 years → discounted compute
- **Spot VMs:** Use unused Azure capacity at lower prices; workloads can be evicted

 3. **Maintenance**

- Remove unused resources to reduce costs
- Deleting a VM may not automatically delete related:
    - Storage
    - Networking resources
- Regular resource management prevents unnecessary charges

 4. **Geography**

- Prices vary by region due to:
    - Power
    - Labor
    - Taxes
    - Fees
- Network transfer costs also vary by geography
- **Bandwidth:** Data moving in/out of Azure
    - Some inbound transfers → free
    - Outbound transfers → charged based on billing zones
- **Billing zones ≠ Availability zones**

 5. **Subscription Type**

- Subscription type can include:
    - Free/discounted services
    - Usage allowances
    - Credits
- **Azure Free Trial:** 12-month access to selected products + initial credit + 25+ always-free products (subject to availability)

1. **Azure Marketplace**
- Provides third-party Azure solutions/services
- Examples:
    - Preconfigured servers
    - Specialized software VMs
    - Managed backup solutions
- Cost may include:
    - Azure resource costs
    - Third-party vendor charges
- Vendor determines billing structure
