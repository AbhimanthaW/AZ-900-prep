
- **Purpose:** Estimate potential Azure costs before deployment

- **Online tool:** Configure resources and calculate estimated Azure spending
- **No resources provisioned:** Adding resources to the calculator does **not** create them or generate charges

- Can estimate:
    - Compute
    - Storage
    - Networking
    - Storage type
    - Access tier
    - Redundancy
        
- Can compare:
    - **Regions**
    - **Service tiers**
    - **Redundancy options**
        
- Useful for:
    - Budget planning
    - Architecture decisions
    - Estimating monthly costs
        
- **Prices are estimates only**, not guaranteed final costs
