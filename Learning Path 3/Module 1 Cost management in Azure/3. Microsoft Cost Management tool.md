
- **Purpose:** Analyze, monitor, and control Azure costs
- Main tools:
    1. **Cost Analysis**
    2. **Cost Alerts**
    3. **Budgets**

### 1. Cost Analysis

- Visualize Azure costs by:
    - Billing cycle
    - Region
    - Resource
    - Subscription
    - Resource group
    - Service
- Identify:
    - Spending trends
    - Sudden cost increases
    - Idle resources
    - Costs over time
- Compare accumulated costs against budgets

### 2. Cost Alerts

- Central location for Azure cost alerts
- Types:
    - **Budget alerts:** Spending reaches/exceeds defined threshold
    - **Credit alerts:** Azure Prepayment reaches **90% / 100%** usage
    - **Department spending quota alerts:** EA departments reach configured quota threshold
- Alerts can appear in Azure portal and trigger email notifications

### 3. Budgets

- Set Azure spending limits based on:
    - Subscription
    - Resource group
    - Service
    - Other criteria
- Budget includes an alert threshold
- Can trigger:
    - Email notifications
    - Automation
    - Resource suspension/modification
- Example: Automatically shut down nonproduction resources when spending reaches a threshold
