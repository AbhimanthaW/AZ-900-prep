
- **Tags:** Metadata (name + value) attached to Azure resources
- Used to organize resources and manage cloud usage/costs
- Related resources can also be organized using **subscriptions** and **resource groups**

### Tag Use Cases
- **Resource management:** Identify workload, environment, team, owner
- **Cost management:** Track costs, budgets, cost centers, forecasts
- **Operations:** Classify resource criticality → support SLA planning
- **Security:** Classify data (e.g. Public, Confidential)
- **Governance & compliance:** Identify regulatory requirements; enforce standards
- **Automation:** Group resources for automated actions/deployments
    
### Common Starter Tags
- `Environment`
- `Owner`
- `CostCenter`
- `Workload`

### Managing Tags
- Methods:
    - Azure Portal
    - PowerShell
    - Azure CLI
    - ARM templates
    - REST API
        
- **Azure Policy:** Enforce tagging rules and conventions
    - Require tags on new resources
    - Reapply removed tags
        
- Tags **do not inherit** automatically from subscriptions/resource groups

### Example Tags

|Tag|Purpose|
|---|---|
|`AppName`|Application name|
|`CostCenter`|Internal cost center|
|`Owner`|Responsible owner|
|`Environment`|Prod / Dev / Test|
|`Impact`|Mission-critical / High-impact / Low-impact|

- Not every resource needs every tag
- Tags can be applied selectively based on organizational needs
